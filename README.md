# Medial-Calcification-Hemodynamics
Matlab codes to simulate blood flow in calcified and healthy arteries

Notes:

1) The blood flow is 1D; the artery is straight; velocities in the transverse directions are ignored
2) The code allows for a tapering of the artery
3) Inlet boundary condiiton is a given pressure function
4) Outlet boundary condition is modeled with Windkessel elements
5) Mechanical properties of the arterial wall are specified through a "tube law" which is derived from a hyperelasticity problem
6) The mechanical properties can be adjusted to simulate heathy and calcified arteries
7) More details can be found from Fok et al. Journal of Physiology (2025)
